MoviesAura V13 — Firebase Foundation (Step 1)

Base: V12

Applied:
- Preserved the complete V12 UI and clickable-card foundation.
- Added a dedicated Firebase Web configuration file at js/firebase-config.js.
- Added js/firebase.js as the reusable Firebase/Firestore initialization layer.
- Added the Firebase App and Firestore browser SDKs to index.html.
- Created the initial Firestore collection reference as `contents`.
- Firebase does not initialize while placeholder configuration values remain.
- No service-account credentials, private keys, or passwords are stored in the site.

Firebase setup path:
1. Create/register a Firebase Web App in the Firebase project.
2. Copy its Web App configuration into js/firebase-config.js.
3. Create/enable Firestore Database in the Firebase console.
4. The site foundation will expose:
   window.MoviesAuraFirebase.db
   window.MoviesAuraFirebase.contents

Current scope:
- This version establishes the Firebase foundation only.
- Homepage/card data migration, admin operations, pagination, language queries,
  detail routing, episodes and download management are separate implementation
  steps and are not silently added here.

Important:
- Existing V12 visual design and content cards are preserved.
- The dedicated notes file is retained as the implementation map.
